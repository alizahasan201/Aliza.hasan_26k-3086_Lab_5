# Topics in lab 05

### 1. Nested Decision Structures

Nested decision structures are used when one decision statement is placed inside another. They help handle situations where multiple conditions need to be checked in a specific order.

### 2. Nested If-Else Statements

A nested `if-else` statement is an `if-else` block placed inside another `if` or `else` block. It is useful when one condition depends on the result of another condition.

### 3. Nested Switch-Case Statements

A nested `switch-case` statement is a `switch` statement placed inside an existing `case` statement. It allows further choices to be made based on the first selection.

### 4. Operators in C

#### Arithmetic Operators

* `+` Addition
* `-` Subtraction
* `*` Multiplication
* `/` Division
* `%` Modulus
* `++` Increment
* `--` Decrement

#### Relational Operators

* `==` Equal to
* `>` Greater than
* `<` Less than
* `!=` Not equal to
* `>=` Greater than or equal to
* `<=` Less than or equal to

#### Logical Operators

* `&&` Logical AND
* `||` Logical OR
* `!` Logical NOT

#### Bitwise Operators

* `&` Bitwise AND
* `|` Bitwise OR
* `^` Bitwise XOR
* `~` Bitwise Complement
* `<<` Shift Left
* `>>` Shift Right

### 5. Ternary Operator

The ternary operator is a shorthand form of an `if-else` statement. It uses the syntax:

```c
(condition) ? expression1 : expression2;
```

It is useful for writing simple conditional statements in a shorter form.

### 6. Comma Operator

The comma operator is used to link related expressions together.

Example:

```c
int a, c = 5, d;
```

### 7. `sizeof` Operator

The `sizeof` operator returns the size of data such as constants, variables, arrays, and structures.

### 8. Operator Precedence

Operator precedence determines the order in which operators are evaluated in an expression. Operators with higher precedence are evaluated first.

### 9. Math Library Functions

The C math library provides functions for performing common mathematical calculations.

```c
#include <math.h>
```
